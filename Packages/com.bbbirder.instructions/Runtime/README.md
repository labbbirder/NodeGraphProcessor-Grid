# Instructions

This would be the meta-module for all visual scripting functionalities.

* When it fitted in ability editor, the action node can be replaced by an instruction, so does the graph itself.

* When it fitted in behave editor, such as FSM, BT, GOAP, and any other visual diagram, the node can directly represent an instruction, or utilize an instruction in a serialized property.

* Specially, when an unit needs an approach to get collection, and then filter, sort, take, select as a query result, there should be a mechanism to pass arguments.
